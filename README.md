### Projeto em destaque

**[Agente de suporte NovaByte](https://github.com/gabrielbarbosapessoa/agente-suporte)**

Agente de atendimento com Agentic RAG em LangGraph, construído do zero ao deploy:

| | |
|---|---|
| **RAG** | busca híbrida (vetorial + full-text com RRF) e rerank escolhido por eval: 100% de acerto, MRR 0,80 |
| **Segurança** | guardrails em camadas com Llama Prompt Guard 2, máscara de dados pessoais e proteção contra IDOR |
| **Qualidade** | evals de roteador, retrieval, respostas (LLM como juiz) e guardrails; CI com bandit, pip-audit e gitleaks |
| **Operação** | LangSmith para traces e custo (~US$ 0,001 por pergunta), FastAPI com streaming |
| **Nuvem** | AWS com Terraform: ECS Fargate, ALB, RDS com pgvector, Secrets Manager |
